# Сервис моделирования трасс подключения к тепловым сетям

Кейс «Лидеры цифровой трансформации» 2026, Департамент информационных технологий города Москвы.
Java 11, Spring Boot 2.6.3, Maven. Правила расчёта берутся из **актуального технического приложения** и
«Разъяснений по вопросам ЛЦТ»; при расхождении с общим ТЗ (PDF) действуют они.

## Что уже сделано (до построения трасс)

| Часть | Что делает | Где |
|---|---|---|
| Загрузка и проверка файла | Потоковое чтение GeoJSON, проверка структуры, геометрии, типа геометрии по типу объекта, обязательных атрибутов, уникальности id (строка `"1"` и число `1` — разные) | `GeoJsonInspector`, `GeoJsonGeometryValidator`, `GeometryChecker`, `UploadController` |
| Существующая сеть | Участки, камеры, источник в метрах (EPSG:32637). Примыкания к камерам по правилу приложения, связность с источником, диаметр не уменьшается к источнику | `ExistingNetworkBuilder`, `Utm`, `Geo` |
| Диагностика данных | Замечания к данным выводятся пользователю: файл принят, но на что-то стоит обратить внимание | поле `warnings` ответа `/api/upload`, блок «Диагностика данных» на странице результатов |
| Интерфейс | Страница загрузки, страница результатов с картой (OpenLayers), слои и легенда, вкладки «Решение 1–3» (пока пустые), защита от случайной перезагрузки | `static/` |
| Дороги OpenStreetMap (демо) | Оси дорог из OSM для области данных, хранятся в памяти, исходный файл не меняется | `road-enrichment.js`, `road-demo.js` |

## Что проверяется при загрузке

**Ошибки** (файл отклоняется, код 400): некорректный JSON (с указанием строки), неверная геометрия или координаты вне диапазона,
тип геометрии не подходит типу объекта, нет `id` или он повторяется, нет `object_type`, нет `restriction_type`,
у участка `heat_network` нет `diameter` или он не из таблицы 1, у точки подключения нет `flow_tph` или он отрицательный.

**Замечания** (файл принят, код 200): нет источника или их несколько; камера не лежит на сети; к камере примыкает больше
4 участков; участки не связаны с источником; в сети замкнутые контуры; диаметр уменьшается к источнику; в файле
объекты, которых нет в базовом составе; типы ограничений, которых нет в таблице 2; нулевой расход точки.

## Расчёт трасс (в работе, пакет `ru.heatplanner.plan`)

Сделаны два первых этапа по схеме «граф видимости + A*»; в веб-интерфейс пока не подключены.

| Часть | Что делает |
|---|---|
| `Rules`, `RuleSet` | Таблицы 1 и 2 приложения как данные; настройки и трактовки, которых приложение не задаёт |
| `PlanInput` | Разбор входа в метры (UTM 37N) на JTS; дороги-оси с шириной превращаются в полосу, без ширины остаются линией (ROAD_WIDTH_REQUIRED) |
| `ObstacleSet` | Запретные зоны по ДУ: отступ таблицы 2 + половина габарита объекта + половина ширины пары труб; проверка всей длины отрезка, растровый предфильтр |
| `Router` | Граф видимости, A* с направлением и метками «длина/цена», поворот не больше 90°, предельная длина ДУ, атомарный специальный проход через дорогу (вход не менее 45°, полоса плюс по 3 м) |
| `Start` | Финальный прямой участок к точке подключения внутри здания ОКС (режимы `NEAREST_ONLY` и `NEAREST_VALID`) |

Тесты: `src/test/java/ru/heatplanner/plan` (31 проверка), запуск `mvn test`.
## Что ещё не сделано

Совместное подключение и структура сети (beam search), подбор диаметров на дереве, камеры и врезки, три варианта,
валидатор результата, выгрузка, подключение расчёта к интерфейсу, PostgreSQL/OpenSearch, Swagger (springdoc-openapi-ui 1.7.0), docker-compose, режим с глубиной,
обработка файлов до 3 ГБ без загрузки в память (сейчас существующая сеть держится в памяти).
Ранний прототип расчёта по **устаревшей** модели (с реконструкцией и `tie_in`) сохранён в теге
`wip/solver-3-solutions-2026-09-23` и в новую модель не переносился.

## Запуск

```
mvn clean package
java -jar target/heat-network-planner-1.0-SNAPSHOT.jar
```

Страница: http://localhost:8080 (порт можно сменить `--server.port=8090`).

## Проверки

Тестовые файлы лежат в `test-data/`; ожидаемый результат по каждому записан в `scripts/check-test-data.ps1`.
При работающем сервисе:

```
powershell -File scripts\check-test-data.ps1 -Base http://localhost:8080
node src\test\js\road-enrichment.test.cjs
```
